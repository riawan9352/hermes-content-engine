# Template Sheet: Reporting

## Cara buat (2 menit)

1. Buka [Google Sheets](https://sheets.new) → buat spreadsheet baru.
2. Ganti nama tab pertama jadi **`Reporting`** (klik kanan tab → Rename).
3. **Cara cepat:** File → Import → Upload → `reporting-sheet.csv` dari
   folder ini.
   **Cara manual:** ketik header di baris 1:

   ```
   No | Link Posting | Views | Likes | Comments | Reposts | Shares | Screenshots
   ```

4. Isi kolom **Link Posting** dengan link post kamu (Threads/TikTok/IG).
   Kolom lain biarkan kosong.
5. Share → General access → **Editor**.

## Prompt

```
[paste link Google Sheets lo]
lihat ke sheet "Reporting"
langsung isi semua views dan engagement sesuai link tertera
```
